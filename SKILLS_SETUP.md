### How to Use Skills

You can invoke skills in your AI assistant using the `@` symbol:

```

```

or

```
@stripe-integration add payment processing to my app
```

The AI will automatically load the specialized knowledge for that skill!

```

```

The AI will:
1. Load brainstorming expertise
2. Ask clarifying questions
3. Help you design the feature
4. Create a plan before coding

### Example 2: Debug an Issue
```
@systematic-debugging My API is returning 500 errors randomly
```

The AI will:
1. Load debugging methodology
2. Analyze the problem systematically
3. Check logs, reproduce the issue
4. Identify root cause
5. Propose fixes

1. Load Stripe integration knowledge

4. Implement subscription logic
5. Add billing portal
